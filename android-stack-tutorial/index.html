地图

先记住这一句

Support Library 是旧世界；AndroidX 是新地址；Jetpack 是官方精选目录；Compose / Lifecycle / CameraX 是目录里三本常用说明书。

名字它是什么你怎么碰到它
Support Library 旧兼容库 android.support.*
AndroidX 新包名与发行体系 androidx.*
Jetpack 官方推荐组件合集 Compose、CameraX、Lifecycle…
Jetifier 迁移期翻译器 把旧依赖改写成 AndroidX
过渡工具

Jetifier：依赖的「改名扫描仪」

构建时扫过第三方 AAR/JAR，把里面的 android.support.* 字节码引用改写成 androidx.*。它不教你写代码，只负责让新旧库能编在一起。

Before
android.support.v7.app.AppCompatActivity
android.support.v4.app.Fragment
→
After
androidx.appcompat.app.AppCompatActivity
androidx.fragment.app.Fragment
代价：构建变慢 CloudPay：依赖已是 AndroidX → 可关闭
发行体系

AndroidX：新地址门牌

Google 把 Support Library 整体搬迁到 androidx.*，让每个库能独立版本演进，并和 Android 平台 API 划清边界。

旧 · Support
android.support.v4…
android.support.v7…

版本和平台纠缠，停在 28.x，不再前进。

新 · AndroidX
androidx.appcompat…
androidx.lifecycle…

各库独立发版，Jetpack 全挂在这套门牌下。

开启 android.useAndroidX=true 是现代工程的默认姿势，不是可选项。

官方目录

Jetpack：精选组件全家桶

它不是新语言，也不是替代 SDK 的操作系统。它是 Google 说「做 App 时优先用这些库」的产品名；落地坐标几乎都是 AndroidX。

UI 层

Compose：用函数画界面

声明式 UI：你描述「现在长什么样」，状态一变，界面按新状态更新。不再靠 XML 布局 + findViewById 手工拼装。

生命周期

Lifecycle：该不该跑

告诉代码：界面现在是创建、可见、还是销毁。配合 ViewModel 存放状态，旋转屏幕也不丢；配合 repeatOnLifecycle，不可见时停止收集 Flow。
