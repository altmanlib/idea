先记住这一句

Support Library 是旧世界；AndroidX 是新门牌；Jetpack 是官方精选目录；Compose / Lifecycle / CameraX 是目录里三本常用说明书。

名字它是什么你怎么碰到它
Support Library 旧兼容库 android.support.*
AndroidX 新包名与发行体系 androidx.*
Jetpack 官方推荐组件合集 Compose、CameraX、Lifecycle…
Jetifier 迁移期翻译器 把旧依赖改写成 AndroidX
过渡工具

Jetifier：依赖的改名器

构建时扫过第三方 AAR/JAR，把里面的 android.support.* 引用改写成 androidx.*。它不教你写界面，只负责让新旧库能编在一起。

改写前
android.support.v7.app.AppCompatActivity
android.support.v4.app.Fragment
→
改写后
androidx.appcompat.app.AppCompatActivity
androidx.fragment.app.Fragment
代价：构建变慢 CloudPay 依赖已是 AndroidX → 已关闭
发行体系

AndroidX：新地址门牌

Google 把 Support Library 整体搬到 androidx.*，让每个库能独立版本演进，并和 Android 平台 API 划清边界。

旧 · Support
android.support.v4…
android.support.v7…

版本和平台纠缠，停在 28.x。

新 · AndroidX
androidx.appcompat…
androidx.lifecycle…

各库独立发版，Jetpack 挂在这套门牌下。

开启 android.useAndroidX=true 是现代工程默认姿势。

Jetpack：精选组件全家桶

不是新语言，也不是浏览器引擎。它是 Google 说「做 Android App 时优先用这些库」的产品名；落地坐标几乎都是 AndroidX。

Compose：用函数画界面
